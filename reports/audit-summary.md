## 安全与维护

已升级可兼容修复的依赖和 React Router；运行时依赖 `npm audit --omit=dev` 未发现已知漏洞。完整依赖检查仍有 7 条构建工具告警（2 moderate、5 high），主要来自 Tailwind 3 的 braces 和 selector-parser 依赖链；不能宣称全部依赖零漏洞。

braces 当时没有补丁版本，见 https://github.com/advisories/GHSA-vfj7-8cjw-p6xm 。构建工具不随静态网页在访客手机上执行，但应限制不可信构建输入，并另行规划 Tailwind 4 迁移与完整视觉回归。

GitHub 仓库当前用于发布 dist，不能代替源码版本管理。原始文件和已校对数据应另行保留版本，发布前运行 npm run build:pages，查看资料报告，并执行 npm run test:browser。
